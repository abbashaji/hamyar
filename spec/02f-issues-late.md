## 2.F.1 How to read this register

- Columns are those of `spec/02b-issues-parts-a.md`: `id` · `severity` · `part` · `fd_ref` · `issue` (one line, as raised) · `resolution applied` (one line, as applied in the part) · `status` · `note`. [D]
- `status` is the part's own status; the three parts use the S0.4 statuses directly, so no mapping is needed. [D]
- `note` is `-` when the row is a faithful copy and no other register row is touched. A note starting `overlap:` or `conflict:` points at another register row; the detail is in `spec/02e-issues-summary.md` (2.E.2). A note starting `recheck:` says that a later file changes a premise of the row. [D]
- Tags `[A]`, `[V]` and `[H]` are those of the raising part. A `[V]` means that a human or another part must verify it; it is not verified here. [D]
- Where this register and a part resolve the same issue differently, `spec/02-issues.md` 2.9 item 3 applies: the central register wins. This file only reports the difference. [D]
